# DebateCoach


**An Evidence-Grounded AI Debate and Rebuttal Coach**

DebateCoach is a machine-learning-powered platform designed to help students and competitive debaters strengthen their argumentation, critical thinking, and rebuttal skills.

## Project Overview

DebateCoach analyzes user-submitted arguments, identifies logical weaknesses, retrieves relevant research, and generates evidence-grounded counterarguments.

Rather than relying solely on language model generation, DebateCoach combines specialized machine learning models with evidence retrieval and verification.

## Core Features

- **Argument Parsing:** Identify claims, premises, and argumentative relationships.
- **Logical Fallacy Detection:** Detect common reasoning errors and explain their implications.
- **Counterargument Retrieval:** Find relevant opposing arguments.
- **Evidence Retrieval and Verification:** Retrieve research and evaluate whether evidence supports or contradicts claims.
- **AI Rebuttal Generation:** Generate structured counterarguments grounded in verifiable evidence.
- **Argument Quality Scoring:** Evaluate clarity, reasoning, evidence, and responsiveness.
- **Debate Practice:** Support interactive debate rounds and personalized feedback.
- **Progress Tracking:** Monitor improvements across practice sessions.

## Technology Stack

**Language:** Python

**Machine Learning:** PyTorch, Hugging Face Transformers, sentence-transformers

**Backend:** FastAPI

**Frontend:** React

**Data and Retrieval:** PostgreSQL, vector search, scholarly research APIs

**Evaluation:** Classification metrics, retrieval metrics, citation verification, and human evaluation

*The technology stack is planned and subject to change during development.*

## Development Status

**Current Phase: Phase 0 — Foundations**

This project is being developed incrementally, beginning with research, dataset preparation, baseline evaluation, and specialized model training.

## Research Goals

1. Develop reliable argument parsing and logical fallacy detection models.
2. Improve counterargument retrieval using semantic search.
3. Reduce fabricated or unsupported evidence in AI-generated rebuttals.
4. Evaluate argument quality using reproducible metrics and human feedback.
5. Investigate whether specialized models improve performance over general-purpose LLM baselines.
